# Prompt Codex berikutnya (dari pengguna, 2026-11-20)

> Jalankan prompt ini ke Codex SAAT LIMIT SUDAH KEMBALI (reset ~5 jam).
> Jangan jalankan sebelum limit kembali.

## Prompt (kata-kata pengguna, jangan diubah)

```
menurutmu aplikasi ini bagaimna? Apa yang perlu di tambahkan, dan kasih aku pertanyaan-pertanyaan agar kamu paham dengan apa yang akan aku buat dari aplikasi ini,
```

## Versi Inggris (terjemahan Muse — dipakai ke Codex supaya hemat token)

```
In your opinion, what do you think of this application? What needs to be added, and ask me questions so you understand what I want to build with this application.
```

## Cara jalankan

1. Pastikan Codex sudah login di VM (`codex login status`).
2. Baca dulu `AGENTS.md` + 3 skill di `docs/skills/` (keamanan,
   Ponytail, UI/UX) dan `STATE.md`.
3. Jalankan Codex di folder repo GENSA dengan prompt di atas.
4. Simpan jawaban Codex + pertanyaan-pertanyaannya ke `STATE.md`,
   lalu laporkan ke pengguna di chat.
